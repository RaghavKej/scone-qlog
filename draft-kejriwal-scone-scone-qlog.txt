                  QUIC Logging for the SCONE Protocol
                 draft-kejriwal-scone-scone-qlog-latest

Abstract

   This document specifies a qlog logging format for sending and
   receiving SCONE packets.

1.  Introduction

   This document defines a way to provide logging for the SCONE protocol
   ([SCONE]) using the qlog format ([QLOG-SCHEMA]).

   ([SCONE]) describes a protocol where on-path network elements can
   communicate their perspective on the maximum sustainable thorughput
   for QUIC flows to endpoints.  This thorughput advice suggests an
   upper bound on long-term average throughput, independent of and
   complementary to real-time congestion control signals.
